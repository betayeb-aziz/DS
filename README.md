# Python Expense Tracker — TP 2

Application console Python de suivi des dépenses.

## Branches
- `main`: version de base du TP 1 (ajout, affichage, total, sortie).
- `feature-delete`: ajoute la suppression d'une dépense (étudiant A).
- `feature-average`: ajoute le calcul de la moyenne (étudiant B).

Les deux fonctionnalités restent volontairement dans des branches séparées, conformément au TP. Elles ne sont pas fusionnées.

## Lancement
Dans Git Bash, depuis ce dossier :
```bash
py expense_tracker.py
```
